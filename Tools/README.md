# Tools

| Tool | What | Arrives |
|---|---|---|
| [`rhp-cli/`](rhp-cli) | REPL and scripting client: `connect`, `exec`, `run`, `stubs`, `blob`, `watch`, `keygen`, `pubkey`, `sign` (replxx + CLI11) | Stage 4 ✅ |

## Rules

- Tools are clients of the public API like any user program.
- Built when `RHP_BUILD_TOOLS=ON` and `RHP_ENABLE=ON` (desktop presets only).

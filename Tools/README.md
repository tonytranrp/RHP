# Tools

| Tool | What | Arrives |
|---|---|---|
| `rhp-cli/` | REPL and scripting client: `connect`, `exec`, `load`, `revert`, `rollback`, `pin`, `stubs`, `watch`, `run`, `keygen`, `sign` (replxx + CLI11) | Stage 4 |

## Rules

- Tools are clients of the public API like any user program.
- Built when `RHP_BUILD_TOOLS=ON` (desktop presets only).
